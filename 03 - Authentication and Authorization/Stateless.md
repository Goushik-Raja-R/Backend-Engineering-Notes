
## Definition

Stateless means the server does not remember previous requests. Every request is independent.

## When to use

Use stateless architecture when:
- Building REST APIs.
- Building microservices.
- Running applications on multiple servers.
- High scalability is required.

The client sends all required information (e.g., JWT, API Key) with every request.

## Examples

- Amazon
- Netflix
- Google APIs
- REST APIs
- Microservices
