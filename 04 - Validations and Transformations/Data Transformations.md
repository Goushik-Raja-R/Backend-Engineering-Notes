
## Definition

> **Data Transformation** is the process of modifying, cleaning, or converting data from one format into another usable format.

---

# Examples

Input

```json
{
  "name": "  Goushik  ",
  "age": "22",
  "email": "GOUSHIK@GMAIL.COM"
}
```

After Transformation

```json
{
  "name": "Goushik",
  "age": 22,
  "email": "goushik@gmail.com"
}
```

---

# Common Data Transformations

- Trim whitespace
- Convert String → Number
- Convert String → Boolean
- Convert String → Date
- Convert to lowercase
- Convert to uppercase
- Format phone numbers

---

# Why is it Important?

- Keeps data consistent.
- Reduces errors.
- Makes processing easier.
- Improves data quality.
